## 📜 The Lore & Vibe

Ever wondered how LLMs like GPT-4, LLaMA, or Claude actually read human language without losing their mind? They don't read words; they read numbers generated by **Byte-Pair Encoding (BPE)**. 

Instead of using some bloated library that does everything for us in 0.001 seconds, this is a **raw, handcrafted subword tokenizer built from absolute scratch**.

Section 4: Key Features
Markdown
## ✨ Key Features

- **📊 Pair Squeezing Engine:** Aggressively finds the most common letter combos and merges them into fresh subwords.
- **🔤 Pre-baked Character Space:** Seeds standard alphabets, numbers, symbols, and whitespace right out of the box.
- **💾 JSON Brain Surgery:** Exports learned vocabulary directly to `text.json` so your learned tokens don't instantly evaporate when the script finishes.
- **🔄 Bidirectional Translation:** Translates raw strings into integer arrays (`tokenizer()`) and mashes them right back into human words (`decode()`).
Section 5: Quick Start Code
Markdown
## 🚀 Quick Start

Drop the code in your main file and let it rip:

```python
from bpe import BPE

# Instantiate the tokenization beast
tokenizer = BPE()

# Random sentences for training
corpus = """
He watched the dancing piglets with panda bear tummies in the swimming pool.
I don’t respect anybody who can’t tell the difference between Pepsi and Coke.
He stepped gingerly onto the bridge knowing that enchantment awaited on the other side.
"""

# Run 7 rounds of pair merging chaos
tokenizer.train(corpus, no_times=7)

# Convert raw text into numerical token IDs
token_ids = tokenizer.tokenizer(corpus)

print("\n--- RESULTS ---")
print("Generated Token IDs:\n", token_ids)

### Section 6: How It Works & Roadmap

```markdown
## 🧠 Under The Hood (Mechanical Chaos)

[ Raw String ] ──► [ Split Chars ] ──► [ Count Pairs ] ──► [ Merge Top Pair ] ──► [ Dump to JSON ]


1. **Populate ASCII:** Maps `a-z`, `0-9`, and every obscure symbol into `vocab_list`.
2. **Frequency Hunt:** `Counter()` scans adjacent characters (`"p" + "a"` $\rightarrow$ `"pa"`).
3. **Subword Fusion:** The most frequent pair gets crowned as a new official token.
4. **ID Assignment:** Assigns integer IDs to subwords and saves the map to `text.json`.
